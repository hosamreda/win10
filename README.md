# Vectorizer (self-hosted)

أداة بايثون خفيفة لتحويل الصور النقطية إلى رسومات SVG نظيفة، مع التحكم في عدد الألوان، مستوى التنعيم، وحدود التفاصيل. تم بناؤها لتقريب تجربة vectorizer.ai محليًا دون الاعتماد على خدمات سحابية.

## المتطلبات

- Python 3.10+
- اعتماديات بايثون الموجودة في `requirements.txt`

قم بالتثبيت:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## الاستخدام السريع

```bash
python -m vectorizer.cli input.jpg -o output.svg --palette-size 16 --blur-radius 0.6 --contour-tolerance 1.2
```

خيارات مهمة:

- `--palette-size`: عدد الألوان التي يتم الاحتفاظ بها بعد التكميم.
- `--blur-radius`: نصف قطر Gaussian blur للتخلص من الضجيج قبل التكميم (عيّن 0 لتعطيله عبر `--no-blur`).
- `--contour-tolerance`: كلما زادت القيمة كان الشكل أنعم، وكلما قلت حافظ على تفاصيل أكثر.
- `--min-area`: تجاهل الأشكال الصغيرة جدًا (بالبكسل المربعة المكافئة).
- `--alpha-threshold`: تجاهل البكسلات الشفافة جزئيًا قبل البحث عن الحواف.

ستحصل على SVG يضم مضلعات مرتبة تنازليًا حسب المساحة لضمان ظهور الأشكال الكبيرة أولًا.

## كيف تعمل

1. **التمهيد والتنقية**: تُفتح الصورة وتُحول إلى RGBA مع Gaussian blur اختياري لإزالة الضجيج.
2. **تكميم الألوان**: استخدام `Pillow` لتقليل عدد الألوان إلى لوحة صغيرة قابلة للتتبع.
3. **استخراج المسارات**: لكل لون، تُبنى أقنعة ثنائية ثم تُستخلص الحدود عبر `skimage.measure.find_contours` مع تبسيط متعدد الأضلاع.
4. **تجميع SVG**: تُكتب كل حدود كمضلع مملوء بـ `svgwrite`، مع الحفاظ على ألفا اللون الأصلي.

## الاختبارات

شغّل الاختبارات للتحقق من خط الأنابيب:

```bash
pytest
```

يحتوي الاختبار على صورة تركيبية بسيطة لضمان إنتاج أشكال متعددة وملفات SVG صحيحة.

## نصائح للنتائج الاحترافية

- حاول العمل على صور بحد أدنى من الضوضاء؛ قلل الحجم قبل التتبع إذا كانت الصورة ضخمة.
- ارفع `palette-size` للحصول على تدرجات أغنى، أو اخفضه لنتائج مسطحة جريئة.
- استخدم `--contour-tolerance` الأكبر لتنعيم المنحنيات، أو الأصغر للحفاظ على التفاصيل الدقيقة.
- إذا كان لديك مناطق شفافة، اضبط `--alpha-threshold` لضبط كيفية تجاهل الخلفيات.
